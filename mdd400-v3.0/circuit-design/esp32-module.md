:::note[Hardware version]

MDD400 **v3.0** — ESP32-P4 / MIPI-DSI / LVGL platform re-base. This board is at **schematic-capture** stage; no V3.0 hardware exists yet.

**Other versions:** [v2.9 — fabricated prototype (current)](/mdd400/v2.9/)

:::

:::info[Under construction — V3.0 capture in progress]

The host block is fully reworked for V3.0 — a chip-down **ESP32-P4** SoC (replacing the ESP32-S3-WROOM-1 module), its external **W25Q256 32 MB flash**, the compulsory **40 MHz** and optional **32.768 kHz** crystals, the reset/boot network, and the **ESP-PROG** programming header. The **ESP32-C6** companion radio and the external flash are drawn on this sheet; the radio has its own page.

This page will be generated from the V3.0 schematic during capture. See the [Tasks](/mdd400/v3.0/tasks) page for status.

:::
