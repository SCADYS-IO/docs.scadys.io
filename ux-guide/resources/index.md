# Resources

The Resources are the files a designer or a firmware engineer works from. Each one lives in the private `SCADYS-IO/ux` repository, and each page here says where it is, what makes it and how to use it.

| Page | Covers |
|---|---|
| [Palette](./palette.md) | `tokens/palette.json`, its previews and rule check, and the swatch libraries |
| [Fonts](./fonts.md) | Noto Sans and B612, their licences, the heavier B612 trials and how a font reaches the firmware |
| [Master files](./master-files.md) | The VectorCraft page masters, the dial template, the safe-area template and the exported badge shapes |
| [Layer scheme](./layer-scheme.md) | The `CODE`, `ART` and `REF` layers, asset IDs and the push to the bench display |
