# Patterns

The Patterns describe how a page behaves over time and under a finger. They cover what a value shows when its data fails, how an alert asks for attention, which gesture does what, and how a setting is changed and confirmed without a keyboard.

| Page | Covers |
|---|---|
| [Data states](./data-states.md) | Valid, no data, stale and alert, and the cue when a data source changes |
| [Alerts](./alerts.md) | Where an alert appears, how it throbs, how it is snoozed and cleared, and the alerts list |
| [Gestures](./gestures.md) | The system gestures that replace the missing buttons, the page gestures and the thresholds behind them |
| [Page navigation](./page-navigation.md) | Moving between pages, the way home, and closing a dialog or panel |
| [Settings and confirmation](./settings-and-confirmation.md) | The order of preference for controls, confirmation of consequential actions, and undo |
| [Lock and wake](./lock-and-wake.md) | The always-on display, manual lock, auto-lock and unlock |

Every pattern follows the Foundations, in particular [Touch accessibility](../foundations/touch-accessibility.md).
